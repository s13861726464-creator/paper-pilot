 # PaperPilot

AI-powered paper assistant built with FastAPI.

## Project Overview

PaperPilot is a backend system for an AI paper assistant.
The project is built step by step toward an AI Agent application.

## Tech Stack

- Python
- FastAPI
- SQLite
- Git

## Current Features

- Basic backend API
- Task management
- SQLite database integration

## Run Locally

Install dependencies:

```bash
pip install fastapi uvicorn
```
